# MajlisAlpha Investment Readiness Gate

The readiness gate sits between a research question and the generated memo. Its job is to be honest about whether an answer is a useful demo, an analyst-review draft, or potentially ready for investment committee review.

The gate checks citation count, source quality, REAL source mix, required source coverage, company focus, and open blockers. It should make demo-only evidence visible, route the next source gap, and keep valuation language tied to evidence rather than presenting a price target.
