# Investor Update Composer

The Investor Update Composer is the v61 workflow layer after the Investor Momentum Ledger. It exists for the moment when the founder knows which relationship matters and needs to send a short, credible update that does not overstate traction.

The composer blends the Investor Data Room, Investor Momentum Ledger, Founder Board Pack, Founder Revenue Forecast, Account Health Command Center, Pilot Proof Packet, evidence ledger, source records, reviews, deployment checks, and warm relationship motion into one update score. The goal is simple: write the update with proof, traction, and one clear ask while keeping unresolved gaps visible.

The live surface contains six cards: update readiness, proof spine, revenue signal, customer signal, source moat, and next ask. It also contains six draft blocks for subject, opening, proof, market pull, moat, and ask. Each draft block routes back to the workflow that can improve it.

Use the primary action to open the next update gap. Use Open momentum ledger to return to relationship priority. Copy investor update creates a founder-ready text note, while Export update JSON saves the underlying proof and draft signals for review.
