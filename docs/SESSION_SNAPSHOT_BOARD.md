# Session Snapshot Board

The Session Snapshot Board is the operator note for a MajlisAlpha testing session. It gives the founder, reviewer, or pilot operator one place to see what the current browser session has actually proved before sharing the live URL, exporting notes, or continuing the next workflow.

## Purpose

The board summarizes the current answer, active citation mix, source-pack status, review trail, pilot activity, weighted revenue signal, deployment health, and the next recommended action. It is designed for the practical moment after a user says "let me test this version" or after a pilot call produces feedback that should not disappear inside separate panels.

## What It Reads

- Current answer and evidence quality from the latest research run.
- Active citations, split by REAL, imported, and SYN starter evidence.
- Source Pack Studio records and uploaded documents in browser storage.
- Memo Review Room decisions and Decision Journal entries.
- Pilot Sessions, Follow-Up Board, Outreach Composer, and Conversion Pipeline records.
- Pages Deployment Doctor score and version health.

## Operating Rule

The next action should always move the desk toward a more defensible or more commercial state. If there is no answer, the board routes to the answer desk. If the answer cites SYN evidence, it routes to the source studio. If source and answer are credible but no human review exists, it routes to the review room or decision journal. If the research trail exists but no pilot motion exists, it routes to the pilot workflow. If the pilot pipeline exists, it routes to Pages Doctor before the link is shared again.

## Export Use

Use Copy Snapshot for quick chat, email, or upload notes. Use Export Snapshot JSON when saving a structured session record for later review. The exported file is an operating artifact only; it is not investment advice and should not be presented as a recommendation.

## Release Checklist

Before calling a build ready, open the board and confirm:

- The displayed version matches the intended release.
- The session score is sensible for the work performed.
- The evidence mix does not hide SYN starter evidence.
- The next action points to the right workflow.
- The Pages Deployment Doctor card remains green after upload.
