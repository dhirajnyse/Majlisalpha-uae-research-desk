# MajlisAlpha Source Collection Assistant

The assistant guides a user from a missing source slot to a usable source record. The key actions are Open source site, Fill URL, paste source text, Detect and fill builder, then Add source.

## UAE Source Path

Use company IR pages for annual reports and presentations. Use ADX disclosures, DFM disclosures, Nasdaq Dubai CANDI, and SCA pages for exchange announcements, ownership updates, and regulatory context. The app should keep source URL, issuer, market, period, and date visible before a source can be treated as REAL.

Do not hide uncertainty. If a source is not REAL, MajlisAlpha should continue to label the answer as prototype evidence.
