# MajlisAlpha Memo Review Room

The Memo Review Room separates machine-assisted drafting from human judgement. A reviewer can save a decision such as Needs source work, Pilot memo ready, Committee review ready, Watchlist only, or Reject thesis.

Each saved review stores memo score, confidence, evidence quality, REAL source coverage, open gaps, citation metadata, conviction, owner, note, and next action. This creates the first local audit trail for UAE research decisions before a production database exists.
