# Investor Intro Room

The Investor Intro Room turns the MajlisAlpha Investor Data Room into targeted founder outreach. It is designed for moments when the product story is strong enough to ask for help, but the ask still needs to be specific, proof-backed, and routed to the right next action.

## What It Checks

- Intro readiness, using the data-room score, board pack, diligence room, proof packet, revenue forecast, and follow-up motion.
- Message proof, so the note is grounded in the UAE wedge, deployment health, source discipline, and current product evidence.
- Ask quality, so the founder is asking for one practical critique, commercial-readiness read, pilot introduction, or dated follow-up.
- Evidence hook, using verified proof entries, source rows, and proof-packet strength.
- Follow-up motion, using saved outreach drafts, memo reviews, and decision-journal activity.

## How To Use It

Open Investor Intro Room after reviewing the Investor Data Room. Read the readiness score first, then inspect the four drafts: Advisor, Investor, Partner, and Follow-up. If a draft is marked weak, use its button to open the next gap before sending anything externally. Copy the intro pack when the message is ready, or export the JSON if you want a structured handoff record.
