# MajlisAlpha Real Filing Capture Mode

Real filing capture is the last checkpoint before evidence enters the corpus. It previews issuer, ticker, source type, period, useful sections, and readiness impact before the user adds the record.

REAL records require three confirmations: the official URL is verified, the text was copied from that same source, and the period/date were checked. Training samples should remain imported review evidence and should never be saved as REAL by accident.

For UAE coverage, the capture flow should be especially strict around exchange disclosures, dividends, related-party transactions, ownership changes, financing updates, and project announcements.
