# Pilot Value Proof Center

The Pilot Value Proof Center turns a MajlisAlpha pilot session into a clear evidence story for a paid pilot. It is designed for the moment after the seven-day success plan starts showing activity, when the founder needs to answer a simple commercial question: what exactly did the user value, what proof supports it, and what should be asked next?

Use this center after the Pilot Success Plan Center. It reads the current browser session, including the latest brief, source-pack coverage, memo reviews, pilot sessions, follow-ups, outreach drafts, conversion records, and the seven-day success plan. It then produces a value score, six proof cards, and a proof-point list that can be copied into a founder update, customer follow-up, or conversion note.

## Proof Model

- Use case proof: confirms whether the pilot user has a specific UAE market question or account workflow.
- Source proof: confirms whether uploaded or source-pack evidence is present, and whether the memo cites official records.
- Repeat proof: checks whether the user asked again, created follow-ups, or moved beyond a single demo.
- Output proof: checks whether the brief, memo packet, export, or committee-ready artifact exists.
- Workflow proof: checks whether reviews, decisions, onboarding, and success-plan actions are moving.
- Revenue proof: checks whether outreach, pricing, expected AED MRR, or paid-pilot intent is visible.

## Operating Rhythm

1. Run a real pilot question and generate a brief.
2. Open the Brief Workbench and confirm the source map.
3. Capture at least one memo review or decision.
4. Use the Pilot Success Plan to pick the next seven-day action.
5. Open the Pilot Value Proof Center and copy the proof summary.
6. Prefill the Pilot Conversion Pipeline when the evidence is strong enough to ask for a paid pilot.

The center should stay practical. It does not replace customer discovery; it keeps discovery from becoming vague by forcing each commercial claim to connect back to visible usage, source trust, repeat behavior, and a next action.
