# MajlisAlpha Compliance Audit Center

Compliance Audit Center keeps MajlisAlpha clear, reviewable, and safe for pilot export. It does not turn the product into legal or investment advice. It gives the team the controls needed to keep research outputs source-backed, non-advisory, and auditable.

## Core Boundary

MajlisAlpha is research software, not investment advice. Exports should separate:

- Source-backed evidence.
- Analyst judgment.
- Valuation scenarios.
- User decisions.

No output should present a buy, sell, or hold instruction as advice.

## Control Areas

The first control set covers:

- Research boundary.
- Source provenance.
- Review audit trail.
- File and source intake safety.
- Export controls.

Each area has checks that must be visible before the product scales beyond a narrow pilot.

## Audit Events

Track events such as:

- Source imported.
- Source marked REAL.
- Claim reviewed.
- Answer quality scored.
- Memo approved.
- Brief exported.
- Customer signal recorded.
- Mission closed.

These events help explain how a brief moved from source intake to export.

## Export Gate

Each exported brief should carry:

- Brief ID.
- Ticker.
- Source list.
- Claim trace status.
- Answer quality score.
- Reviewer status.
- Non-advisory disclaimer.
- Unresolved gaps.
- Export timestamp.

If an output contains source-blocked material, missing disclaimer, or unreviewed claims, it must not be marked share-ready.
