# MajlisAlpha Source Intake Doctor

The Source Intake Doctor checks whether a proposed source is strong enough before it enters the live corpus. It scores official URL quality, issuer match, ticker match, period/date clarity, citation depth, source type, and REAL-source confirmations.

High-priority blockers include missing https URL, weak citation text, training sample marked REAL, mismatched issuer, or incomplete confidence checks. For UAE markets, the doctor should prefer official company IR, ADX, DFM, Nasdaq Dubai CANDI, SCA, or verified issuer pages.
