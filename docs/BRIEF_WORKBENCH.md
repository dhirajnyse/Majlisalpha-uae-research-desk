# MajlisAlpha Brief Workbench

The Brief Workbench sits between answer generation and research export. It scores whether the current UAE-market answer has enough evidence to become a pilot memo.

The score checks for a generated answer, at least three citations, source-type spread, evidence quality, REAL citation mix, and company-level source coverage. Copy memo packet creates Markdown with the question, brief, readiness checks, evidence, and open source gaps. Export packet JSON saves the same structure for a future backend audit trail.

Open next source gap routes directly into the Source Pack Studio when an issuer still lacks annual report, earnings call, results, ownership, or exchange disclosure evidence.
