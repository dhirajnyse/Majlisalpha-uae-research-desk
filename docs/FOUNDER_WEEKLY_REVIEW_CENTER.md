# Founder Weekly Review Center

The Founder Weekly Review Center is the operating memo for MajlisAlpha. It rolls up deployment health, demo proof, pilot learning themes, source readiness, commercial signal, follow-up discipline, and release posture into one weekly decision board.

Use it after every meaningful demo cycle. Start by opening Pages Doctor, Live Smoke Test, Pilot Demo Script, and Pilot Learning Loop, then open the Founder Weekly Review Center to see the current weekly proof score. The score is not a vanity metric; it is a prompt to decide what changed this week and what must happen next.

Recommended cadence:

1. Confirm the live site is healthy and the version is current.
2. Run or review at least one pilot demo script.
3. Capture session notes, trust objections, source blockers, paid intent, and next dates.
4. Review the learning loop queue and promote the top source, trust, product, or revenue action.
5. Export the founder memo and use it as the weekly operating note before the next upload.

The board should answer six founder questions: is the live product stable, did a real user see value, what evidence gap is blocking trust, which follow-up deserves attention, is there any paid intent, and what release action should ship next. If the answer is unclear, the next action should be concrete enough to open inside the desk.

The center is intentionally browser-local. It reads the current session state, imported sources, pilot records, reviews, decisions, and deployment checks without sending private notes anywhere. For a public repo release, treat exported founder memos as operational notes and remove any private user names before sharing outside the project.
